# Gerador de Crachá Virtual

Um projeto simples feito em grupo para praticar HTML, JavaScript e o trabalho em equipe com Git e GitHub.

## O que ele faz

Ao abrir a página, o programa pergunta seu nome, sobrenome e ano de nascimento, e também se você é aluno ativo da instituição. Depois, mostra um crachá na console do navegador, assim:

```
CRACHÁ VIRTUAL: SILVA, Maria
Idade estimada: 25 anos.
O seu primeiro nome tem 5 letras.
Estatuto de aluno ativo: true
```

## Como usar

1. Baixe o projeto:
   ```bash
   git clone https://github.com/DaviDxz33gerador-cracha-js.git
   ```
2. Abra o arquivo `index.html` no navegador.
3. Responda às perguntas que aparecerem.
4. Aperte `F12` e abra a aba **Console** para ver o seu crachá.
